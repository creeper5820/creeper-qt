# md3-token

从锁定 commit 的 Jetpack Compose Material3 源码生成 creeper-qt 组件的 token 头文件。生成结果入库，位于 `src/creeper-qt/details/token/`。

依赖：Python 3（含 PyYAML）、git、clang-format。

## 命令

```sh
python3 tool/md3-token/generator.py fetch      # 按 config.yaml 的 commit 拉取源码到 build/md3-token/androidx
python3 tool/md3-token/generator.py generate   # 根据 details/token/*.yaml 生成头文件
python3 tool/md3-token/generator.py check      # 校验生成结果与仓库一致、include 依赖合规
```

`generate` 和 `check` 不联网；缓存缺失或 commit 不一致时会提示先运行 `fetch`。`check` 失败时以退出码 1 结束，并列出 missing / outdated（附 diff）/ stale 文件和违规的 include。

## 目录

```
tool/md3-token/
  generator.py        入口，分发子命令
  config.yaml         androidx commit、sparse 路径、模块别名、输出目录
  command/            fetch.py、generate.py、check.py
  core/               配置、缓存、Kotlin 解析、引用解析、渲染、依赖规则

src/creeper-qt/details/token/
  unit.hh             手写：creeper::Dp / Sp 与 _dp / _sp
  color.hh            手写：creeper::Color（继承 QColor）
  <component>.yaml    手写：组件配置
  <component>/        生成：values.hh、measurements.hh、colors.hh、defaults.hh
  sys/                生成：被组件引用的 shape / elevation / typography
```

生成文件第一行是 `// GENERATED by tool/md3-token/generator.py. DO NOT EDIT.`，`generate` 只会删除带这个标记的过期文件。

## config.yaml

| 字段 | 说明 |
| --- | --- |
| `androidx.remote` / `androidx.commit` | 源码仓库与锁定的 commit（40 位小写 hex） |
| `cache` | 缓存目录，相对仓库根 |
| `sparse` | sparse checkout 路径 |
| `modules` | 别名到缓存内目录的映射，组件 yaml 用 `<别名>:<文件>` 引用 |
| `output` | 生成目录，相对仓库根，必须在 `src/` 下 |

现有别名：`material3`、`tokens`、`ripple`、`animation`、`text`。

## 组件 yaml

文件名即 `namespace`，生成到 `creeper::token::<namespace>`。yaml 只写数值在 Compose 中的位置，不写数值。

```yaml
namespace: checkbox

tokens:                       # *Tokens.kt；省略 include 时取全部
  file: tokens:CheckboxTokens.kt
  include: [ContainerSize, ContainerShape]

symbols:                      # 组件源码中的具名常量
  - file: material3:Checkbox.kt
    names: [StrokeWidth]
  - file: ripple:RippleAnimation.kt
    unit: ms                  # 生成 std::chrono::milliseconds
    names: [FadeInDuration]

extract:                      # 没有符号名的数值，正则必须恰好 1 个捕获组、恰好匹配 1 处
  - name: FocusRingWidth
    file: material3:Ripple.kt
    match: 'innerStrokeWidth\s*=\s*(\d+)\.dp\b'

measurements:                 # 字段名 -> 值名（必须是 Dp / Sp）
  container_size: ContainerSize

colors:                       # 字段名 -> 颜色
  checked_box_color: SelectedContainerColor                     # tokens 文件中的 ColorSchemeKeyTokens 引用
  unchecked_box_color: transparent
  disabled_checked_box_color: { color: SelectedDisabledContainerColor, opacity: SelectedDisabledContainerOpacity }
  state_layer_color: { scheme: OnSurface }                      # 直接引用 ColorScheme 字段
```

- 值名是 Kotlin 名，生成后加 `k` 前缀（`kContainerSize`）；所有来源合并后不得重名。
- `colors` 的字段和取值以 Compose 的 `XxxDefaults` / `XxxColors` 为准。
- `opacity` 必须引用本组件已收集的 Float / Double 值，不能写数字。
- `{ scheme: X }` 用于 Compose 通过 `contentColorFor` 等取色、没有组件 token 的情况；字段必须存在于 `ColorScheme`。

## 支持的 Kotlin 写法

声明：`inline val X: T` + `get() = V`、`const val X = V`、`val X = V`、`(public|private|internal) val X: T = V`、`private val X` + `get() = V`；可缩进在 object 内，值可跨行。

| Compose 值 | 生成的 C++ |
| --- | --- |
| `N.dp` / `N.sp` | `N_dp` / `N_sp` |
| `Nf`、小数 | `double` |
| 整数 | `int`；带 `unit: ms` 时为 `std::chrono::milliseconds { N }` |
| `RoundedCornerShape(N.dp)` | `N_dp` |
| `CubicBezierEasing(a, b, c, d)` | `CubicBezierSolution { a, b, c, d }` |
| `ShapeKeyTokens.X` | `sys::shape::kX` |
| `ElevationTokens.X` | `sys::elevation::kX` |
| `TypographyKeyTokens.X` | `sys::typography::kX`（`TypeScale`：size、line_height、tracking、weight） |
| `ColorSchemeKeyTokens.X` | 只在 `mapColors` 中使用，映射到 `ColorScheme` 的 snake_case 字段 |

其他写法（`CircleShape`、分角圆角、函数调用等）在被引用时报错，并给出 Kotlin 源码位置。

## include 规则

`details/token/` 下的头文件只能 include：

- `creeper-qt/details/token/...`
- `creeper-qt/utility/theme/color-scheme.hh`
- `creeper-qt/utility/math/cubic-bezier.hh`
- 尖括号形式的系统头和 Qt 头

include `widget/` 或 `layout/` 会被 `check` 拦截。

## 升级 Compose 版本

1. 修改 `config.yaml` 的 `androidx.commit`。
2. `fetch`，然后 `generate`。
3. 审查 `details/token/` 的 diff；报错时按提示修正组件 yaml。
4. `check` 通过后连同组件改动一起提交。

## 开发

Python 代码用 autopep8 格式化，配置在 `setup.cfg`（`max-line-length = 100`）。生成器设置了 `sys.dont_write_bytecode`，不会留下 `__pycache__`。
